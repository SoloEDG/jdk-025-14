# 遗迹探勘

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18225。

## 概率推断引擎

推断笔记基于公开信息（数字、探针结论、玩家旗标假设）生成全图危险概率，不读取暗格答案。

### 求解流程

1. **边界建模**（`lib/frontier.ts`）：区分被数字约束的边界格与未接触任何数字的暗区格；危险与玩家旗标严格分开，旗标可作为确定假设或整体忽略。
2. **连通分组**（并查集）：把共享未知格的线索合并为相互关联的边界组，各组独立求解。
3. **分组求解**（`lib/componentSolver.ts`）：
   - 完整枚举给出精确的分层布局计数（BigInt 防溢出），并保存全部可行布局用于严格均匀抽样；
   - 布局空间或搜索节点超限时自动降级为随机 DFS 抽样。
4. **全局合成**（`lib/global.ts`）：用动态规划把各组按“剩余危险总数”卷积，暗区以组合数 `C(暗区格, 暗区雷)` 计入正确权重，避免把组内等概率误当全图等概率。

### 精确 vs 估计

- **精确值**：全部组完整枚举时输出，可证明某格零风险（`provenSafe`），是“一键安全探索”的唯一依据。
- **估计区间**：任一组降级抽样时整体标注为抽样，给出点估计与 Wilson 95% 置信区间，**永不**产生证明安全结论。

### 异步与失效

`model/useProbability.ts` 在宏任务中求解，不阻塞地图操作；每次公开信息变化递增 `revision`，晚到的旧结果因 revision 落后被丢弃，新局立即清空旧概率。

### 冲突处理

旗标/探针/数字互相矛盾时列出具体冲突来源（哪个数字格、哪些格、声明值与可行区间），不输出误导性的零风险地图。

## 测试

- `npm run test:inference`：概率引擎单元测试（含手工核算对照）
- `npm run test:integration`：真实棋盘端到端、一键探索防御性、存档兼容
- `npm run test:bench`：暴力枚举对照与性能基准
